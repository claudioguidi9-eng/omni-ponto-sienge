CAMINHO A: API REST BIDIRECIONAL (A MAIS MODERNA E RECOMENDADA)
• O robô no WhatsApp recebe o ponto do operário com GPS no canteiro.
• A nossa Engine grava a apropriação de custos no Sienge (CMO) por obra (4h Obra A + 4h Obra B).
• A nossa Engine dispara a jornada de 8h contínua direto para o Control iD via API REST.
• Vantagem: Sem arquivos textos, tudo em tempo real instantâneo no banco de dados.

CAMINHO B: GERADOR AUTOMÁTICO DE ARQUIVO AFD / AFDT (COMPATIBILIDADE FISCAL 100%)

  já assinado com hash e formatação oficial para importar em lote no Control iD ou na folha.
• Vantagem: Zero risco de rejeição por qualquer fiscalização do trabalho (MTE).

CAMINHO C: CONCILIAÇÃO DUAL (OMNI PONTO HUB)
• O Omni Ponto atua como o 'Cérebro Central':
  1. Lê os 496 funcionários e 103 obras do Control iD via API automaticamente.
  2. Sincroniza com as obras e orçamentos do Sienge ERP.
  3. Conduz a conversa pelo WhatsApp.
  4. Devolve o custo no Sienge e o espelho no Control iD.
